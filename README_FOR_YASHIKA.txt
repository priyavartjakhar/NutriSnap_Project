          NutriSnap - Setup Instructions
          Food Calorie Estimation Project
═══════════════════════════════════════════════════

STEP 1: Install Python
──────────────────────
1. Go to https://www.python.org/downloads/
2. Click "Download Python 3.12" (or latest)
3. Run the installer
4. ⚠️ IMPORTANT: CHECK the box "Add Python to PATH" ⚠️
   (This is at the bottom of the first screen)
5. Click "Install Now"
6. Wait for it to finish

STEP 2: Run the App
────────────────────
1. Open the NutriSnap folder
2. Double-click "CLICK_ME_FIRST.bat"
3. First time it will install packages (2-5 min)
4. Browser will open automatically
5. Upload a food photo and click Analyze!

STEP 3: Using the App
──────────────────────
- Upload any food photo (pizza, burger, sushi etc.)
- Click "Analyze" to get nutrition info
- Click "Heatmap" to see where AI is looking
- Click "Training Curves" in navbar to see training graphs
- Click "Onboarding" to replay the intro

TO STOP: Just close the black terminal window.
TO RESTART: Double-click "CLICK_ME_FIRST.bat" again.
